Every object contains all possible properties derived from the default
New object types are created by using capital letters
Every object should have a base and an ID, ID can be given or generated

Anything inside ** is a varible type

to create a new type from a base use !*base*.*TYPE*
Any new type without a base can be definded by using the def(default) base or just defined on its own
E.G !def.NEW or !NEW

to change the new type for all of this type use ~*TYPE*
changing the default will result in an error

to use/create a new object from this type use +*base*.*id*

comments are created using #'s by having one at the start and one at the end of the comment



ACTIONS
Actions animate/control objects on the screen through conditions and instructs
Simple actions can be writen in line but more complex actions can have an action ID and can be defined in their own section
condition > function > end
